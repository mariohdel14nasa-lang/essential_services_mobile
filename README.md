# Essential Sevices
A way to not depend on Google Play Services to get user info

A brand-new way to get user info, such as:
- eMail
- Phone number
- Passwords
- And more (Coming soon)

# How to develop
## How To Build with the direct integration

To access user info, you can make a deep link petition to essentialservices://get.data or essentialservices://. 
Once the petiton is made, Essential Sevices will give user data in a JSON format file with a structure with various fields, such as:
- eMail
- Phone number
- Name
- Tag (unnecesary in most cases)
- Other

## How To Build with the web integration

To access user info, you can also implement the web version of the app, on https://mariohdel14nasa-lang.github.io/essentialservicesweb/.
Once he user signs in into their account, you can access the web's LocalStorage that contais the user's:
- eMail
- Phone number
- Name
- Tag (unnecesary in most cases)
- Other
